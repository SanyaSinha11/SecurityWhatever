### Q1. What is threat modelling? How do you perform threat modelling?
“Before an attacker finds a way to break the system, we try to think like an attacker and identify how the system could be attacked.”
It is generally done during **design/development**, but it can also be performed on existing systems when there are major changes.

Scope → Architecture → Assets → Threats → Risk → Controls → Validate → Monitor
“I would follow Scope → Architecture → Assets → Trust Boundaries → Threat Identification → Risk Assessment → Controls → Validation → Continuous Review.”

### Q2. Suppose you have a fresh cloud environment. What five cybersecurity steps would you take to store PII or any sensitive data?
“If I have a fresh cloud environment and need to store PII, I would first establish a secure baseline. My five major steps would be: identity and access management, network security, encryption and key management, data protection and classification, and monitoring with backup and recovery.”

## Q3. How would you ensure Availability of data in the CIA Triad?
Availability means: **Authorized users should be able to access data and systems when they need them.**
