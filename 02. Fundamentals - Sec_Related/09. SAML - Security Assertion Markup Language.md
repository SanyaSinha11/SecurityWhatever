# Overview
SAML (Security Assertion Markup Language) is an open standard tool used to pass user login and permission data between an identity provider and a service provider. It lets users use single sign-on (SSO) to log in just once and open many apps without typing passwords again.

SAML assertions (claims) are written in eXtensible Markup Language (XML). Communications are established using HTTP/HTTPS and the Simple Object Access Protocol (SOAP). The secure tokens are signed using the XML signature specification. The use of a digital signature allows the relying party to trust the identity provider.

An example of a SAML implementation is Amazon Web Services (AWS) which functions as a SAML service provider. This allows companies using AWS to develop cloud applications to manage their customers' user identities and provide them with permissions on AWS without having to create accounts for them on AWS directly.
