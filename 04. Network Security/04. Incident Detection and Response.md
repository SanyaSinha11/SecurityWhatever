
## Incident Detection
Security tools may observe:
- Unusual outbound traffic
- Large data transfer
- Unknown destination
- Unusual process
- Abnormal user/service account behavior
- Sensitive database access

## Incident Response
1. Detect
2. Validate/Triage - ask questions like what machine, what user/acc, etc
3. Contain - isolate, block, disable, stop malicious process
4. Investigate - determine initial access, intention, impact, file accessed, etc
5. Eradicate - remove the root cause
6. Recover - restore normal operations and monitor for recurrence

##### Reason:
Maybe
- Egress filtering was weak
- DLP policy didn't cover the channel
- Sensitive database wasn't properly classified
- Excessive permissions existed
- Logging was insufficient
